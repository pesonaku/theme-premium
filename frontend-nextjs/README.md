# Frontend Next.js Landing Page Component Kit

Modul ini merupakan representasi komponen Next.js untuk landing page perumahan modern, yang kompatibel dengan tema Blogger `template.xml`.

## Fitur Komponen
- Hero Carousel dengan animasi transisi
- Filter interaktif Rumah Subsidi & Komersil
- Modal popup detail spesifikasi rumah & preview galeri denah
- Integrasi WhatsApp Direct Click-to-Chat
- Dynamic Accordion FAQ
